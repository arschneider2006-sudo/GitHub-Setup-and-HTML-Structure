# Alyssa Schneider Portfolio

## Project Description

This project is a responsive student portfolio landing page created using HTML and CSS. The website introduces me, highlights my skills, showcases projects, and provides a way for visitors to contact me.

## Intended User

Employers, professors, classmates, and anyone interested in viewing my portfolio.

## User Goal

The user should quickly learn who I am, what I study, and view examples of my work.

## Inspiration Interfaces

- Adobe Portfolio
  - Clean project layouts and typography.
- ArtStation
  - Strong visual emphasis on artwork.
- GitHub Pages Portfolio Examples
  - Simple responsive layouts.

## Design Choices

### Layout
Hero section followed by four organized content sections.

### Color
Dark blue-gray palette inspired by my pixel-art profile picture.

### Typography
Arial with clear heading hierarchy.

### Visual Hierarchy
Large hero title, highlighted buttons, and card-based sections.

### Feedback States
Navigation links, project cards, and buttons change appearance when hovered.

### Responsive Design
Navigation stacks vertically and project cards become a single column on smaller screens.
